## 分頁二：合約轉換

### 轉換邏輯（2026-07 改版）

上傳舊版對業主合約，系統自動抽取資料、填入對應公司的新版合作協議書範本輸出。

```
對業主合約 (.docx)
  甲方 = 業主
  乙方 = 志昌 / 瀚昱 / 毅源
         ↓
  1. 偵測乙方公司名稱（志昌／瀚昱／毅源）
  2. 偵測合約類型（租賃型 → 模式A／分潤型 → 模式B）
  3. 從舊合約抽取：建物地址、車位數、合約起訖日期、
       租金金額（租賃型）或 甲乙方分潤比例（分潤型）
  4. 載入對應公司的新版範本（合作協議書_260703）
  5. 接受範本 tracked changes，填入抽取資料
  6. 在選用模式前加上 ■ 標記
  7. XML 格式驗證
         ↓
合作協議書 (.docx)
  甲方（場地經營方）= 志昌 / 瀚昱 / 毅源
  乙方（系統服務方）= 悠勢科技股份有限公司
```

### 自動填入欄位

| 資料來源（舊合約）| 填入位置（新範本）|
|---|---|
| 建物地址 | 第2條「坐落於＿＿＿」|
| 車位數 | 第2條「共計＿＿格停車格」|
| 合約開始日 | 第10條生效日 |
| 合約結束日 | 第10條到期日 |
| 月租金（租賃型）| 模式A「固定新台幣＿＿元整」|
| 甲方%／乙方%（分潤型）| 模式B「甲方分得＿%、乙方分得＿%」|

**已預填於範本（不需從舊合約抓取）：**
- 甲方名稱、代表人、統編、地址、電子郵件
- 甲方銀行帳戶（銀行名稱、帳戶名稱、帳號）
- 乙方（悠勢科技）簽名頁資料

### 模式選取規則

| 舊合約類型 | 新合約模式 |
|---|---|
| 停車位租賃契約書（租賃型）| ■ 模式 A：固定收益制 |
| 停車位服務契約書（分潤型）| ■ 模式 B：營收分潤制 |
| 模式 C（固定兼超額分潤）| 目前舊合約無此類型，未來視需求擴充 |

### 新版範本檔案

| 範本 | 公司 |
|------|------|
| 志昌-悠勢_停車場系統管理與技術服務合作協議書_260703.docx | 志昌資產管理 |
| 瀚昱-悠勢_停車場系統管理與技術服務合作協議書_260703.docx | 瀚昱開發 |
| 毅源-悠勢_停車場系統管理與技術服務合作協議書_260703.docx | 毅源開發 |

> 範本存放於 `自動產生合約範本/` 資料夾，每間公司各自獨立，甲方資料已預填。

### 輸出檔名規則

```
原始檔名(合作協議書).docx

範例：新豐停車場-停車位租賃契約書(對業主合約).docx
  → 新豐停車場-停車位租賃契約書(對業主合約)(合作協議書).docx
```

### 注意事項
- 僅支援 `.docx` 格式，不支援 PDF
- 系統自動識別合約中的公司名稱（志昌資產管理股份有限公司 / 瀚昱開發股份有限公司 / 毅源開發股份有限公司）
- 若合約中找不到上述公司名稱，會回傳錯誤提示
- 舊合約須為系統產生器產出的格式（含關鍵詞：「坐落於」「共計XX格」「生效日」等）
- 上傳的檔案僅在記憶體中處理，不儲存於伺服器

## 注意事項

| 項目 | 說明 |
|------|------|
| 輸入格式 | 僅支援 `.docx`，不支援 PDF |
| 必填欄位 | 詳見上方必填欄位清單 |
| 非必填空白 | 未填的非必填欄位會自動留底線空白，供手寫補填 |
| 所得代號 | 產生器：依勾選填入合約與表頭；轉換器：固定為法人 00 發票 |
| 日期格式 | 系統自動將西元年轉為民國年（顯示於合約內） |
| 乙方% 自動計算 | 分潤型填入甲方%後，乙方%自動補為 100 - 甲方% |
| 銀行帳戶影本 | 瀚昱、毅源轉換後最後一頁自動附上銀行帳戶影本（JPEG） |
| 免費方案限制 | 閒置 30 分鐘後休眠，第一次開啟需等 30～50 秒喚醒 |
| 資料安全 | 合約檔案僅在記憶體中處理，不儲存於伺服器 |
| 使用量記錄 | 每次使用自動寫入 Google Sheets，背景執行不影響速度 |
